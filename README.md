# Math Curriculum Test Builder

بانِي اختبارات رياضيات، مبني من الصفر (clean-room)، ومنظّم حسب الخطة الدراسية لبكالوريوس
الرياضيات (جامعة شقراء، 130 ساعة): **المستوى (Level) ← المقرر (Course) ← الموضوع (Topic)**.
يولّد اختبارات عشوائية متعددة الأقسام مع مفاتيح إجابات، ويعمل كصفحة ويب واحدة بلا أي اعتماديات خارجية.

> المقررات مرتّبة من المستوى الأول إلى الثامن كما في الخطة، ثم المقررات الاختيارية.
> الواجهة بثلاث لغات قابلة للتبديل: **English** و**عربي** و**English + عربي**، وتُحفظ اللغة المختارة في المتصفح.
> يمكن عرض **الحلول بالخطوات** مع الرسوم البيانية، والجدول الإحصائي المستخدم (z أو t أو F) مع تظليل القيمة المقروءة.
>
> **إنشاء التقييمات:** أزرار «ورقة تدريب» و«إنشاء واجب» (5 أسئلة، درجتان) و«إنشاء اختبار فصلي» (3 أسئلة × 5 درجات)
> و«إنشاء اختبار نهائي» (5 أسئلة × 10 درجات). اختر المقرر (أو «جميع المقررات») وحدّد موضوعاً أو أكثر، وبجانب كل موضوع
> عدد الأسئلة ونوعها (مقالي أو اختيار من متعدد). إذا زادت البنود على عدد الأسئلة يُقسَّم السؤال إلى فروع (أ)، (ب)…
> مع توزيع الدرجة عليها. خيار «إضافة صفحة بالجداول الإحصائية كاملة» يُلحق جداول z وt وF كاملة عند الحاجة.
> الأنظمة والقيود والشروط (معادلتان في مجهولين، قيود البرمجة الخطية، الشروط الابتدائية والحدية…) تُكتب في أسطر
> متتالية بمحاذاة علامة = أو ≤ وبقوس معقوف.
>
> **الترقيم:** الأسئلة Q1، وفروعها Q1: A، Q1: B… (بالعربية س1: أ). وبجانب كل موضوع عددان: كم سؤالاً مقالياً وكم سؤالاً اختيارياً.
> **الطباعة / PDF:** زر «تنزيل PDF» يُنشئ ملف PDF مباشرة (بالواجهة الإنجليزية). مع العربية يُنزَّل ملف HTML جاهز للطباعة
> يفتح نافذة الطباعة تلقائياً (اختر «حفظ بصيغة PDF»)، لأن مكتبة PDF ترسم النص العربي بشكل خاطئ. داخل claude.ai يستخدم
> زر «طباعة / PDF» نفس الطريقة لأن نافذة الطباعة غير متاحة هناك.
> تُدرج مقررات الرياضيات والإحصاء فقط (ريض/احص)؛ متطلبات الجامعة والكلية الأخرى غير مُدرجة.

## التشغيل

لا يحتاج أي تثبيت للتشغيل — فقط خادم ملفات ثابت (بسبب استخدام ES Modules):

```bash
npm run dev        # يشغّل python3 -m http.server 8731
# ثم افتح: http://localhost:8731/index.html
```

## البنية

```
index.html              ← الهيكل: يحمّل styles.css و src/main.js
src/
├─ styles.css           ← كل الأنماط
├─ helpers.js           ← دوال مساعدة نقية (أرقام، كسور، مصفوفات، أعداد مركّبة، TRIG)
├─ viz.js               ← نص ثنائي اللغة L()/Li()/M()، محاذاة الأنظمة align()، خطوات الحل steps()، رسوم SVG، جداول z/t/F (مقتطفات وكاملة)
├─ i18n.js              ← نصوص الواجهة بالعربية والإنجليزية
├─ generators.js        ← كائن G: كل مولّدات المواضيع  (gen(d) => {q, a})
├─ curriculum.js        ← بيانات المنهج: المستويات والمقررات وربط المواضيع + فهرس البحث
├─ ui.js                ← بانِي الاختبار (أقسام، نسخ، عرض، حفظ/تصدير) — كل منطق الـ DOM
└─ main.js              ← نقطة الدخول: init()
tests/
└─ generators.test.js   ← فحوص الصحّة (node --test)
```

**مبدأ الفصل:** `helpers.js` و`viz.js` و`i18n.js` و`generators.js` و`curriculum.js` **نقية بلا DOM** (الرسوم تُبنى كنصوص SVG)،
لذا تُستورد مباشرة في اختبارات Node. منطق الواجهة معزول في `ui.js`.

## كيف تُضيف موضوعاً جديداً

ثلاث خطوات:

**1.** أضف دالة مولّدة في [`src/generators.js`](src/generators.js) داخل `G`.
تُعيد `{q, a}` بصيغة HTML (`q` السؤال، `a` الإجابة داخل `<b>`):

```js
myTopic(d) {                         // d = الصعوبة 1..3
  const a = R(2, 9), b = R(2, 9);
  return { q: `${a} × ${b} =`, a: `<b>${a * b}</b>` };
}
```

يمكن أن يُعيد المولّد أيضاً `s`: خطوات الحل بصيغة HTML (`steps(...)`) مع رسم (`plot(...)`) أو جدول عند الحاجة.
للنص ثنائي اللغة استخدم `L('English', 'عربي')`، وضع الرموز الرياضية داخل النص العربي في `M(...)` لتبقى من اليسار لليمين.

**2.** أعطه اسماً معروضاً في `TOPIC_LABELS` (وبالعربية في `TOPIC_LABELS_AR`) داخل [`src/curriculum.js`](src/curriculum.js):

```js
myTopic: 'My topic name',
```

**3.** اربطه بمقرر واحد أو أكثر في `CURRICULUM` (نفس الملف)، داخل المستوى الصحيح:

```js
{ code: 'MATH 244', title: 'Linear Algebra', topics: ['matrixAdd', 'myTopic'] },
```

**4.** (مستحسن) أضف فحص صحّة في [`tests/generators.test.js`](tests/generators.test.js).

> المقررات التي لا يمكن توليد مسائل لها (مشروع التخرج 1 و2، تاريخ الرياضيات) تبقى بقائمة `topics: []`
> فتظهر في الواجهة لكن لا يمكن إضافتها.

## الموقع على الإنترنت وتثبيته كتطبيق

يُنشر البرنامج تلقائياً على GitHub Pages مع كل دمج في `main` (سير العمل `.github/workflows/pages.yml`) على الرابط:
**https://masaker77-coder.github.io/math-curriculum-test-builder/**

- خطوة واحدة لأول مرة: في GitHub افتح **Settings ← Pages ← Build and deployment ← Source** واختر **GitHub Actions**، ثم أعد تشغيل سير العمل «website» من تبويب Actions (أو ادمج أي تعديل).
- الموقع تطبيق قابل للتثبيت (PWA): من Chrome أو Edge يظهر زر «⬇ تثبيت التطبيق» أعلى الصفحة، ومن iPhone: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- بعد أول فتح يعمل بدون إنترنت (عامل الخدمة `sw.js` يحفظ الملفات، ويجلب النسخة الأحدث عند توفر الإنترنت).

## نسخة تعمل بدون إنترنت

`dist/math-test-builder-offline.html` ملف واحد (حوالي 0.9 ميجابايت) فيه البرنامج كاملاً: يُفتح بالضغط مرتين بدون خادم ولا إنترنت، والطباعة تعمل من زر «طباعة / PDF». الملف المضغوط `dist/math-test-builder-offline.zip` يحتويه مع دليل قصير.
لإعادة بنائه بعد أي تعديل: `node tools/build-offline.mjs`.

**إرسال الملف عبر واتساب:** معاينة واتساب في آيفون و«عارض HTML» في أندرويد لا تشغّل البرامج، فيظهر الملف بدون مقررات (ويظهر الآن تنبيه يشرح ذلك). على أندرويد افتح الملف من واتساب بـ «فتح باستخدام ← Chrome». الأفضل مشاركة **رابط الموقع** بدلاً من الملف، لأنه يعمل على كل الأجهزة ويمكن تثبيته. البرنامج مكتوب ليعمل حتى على المتصفحات القديمة (منذ 2018)، مع ملف توافق `src/compat.js`.
